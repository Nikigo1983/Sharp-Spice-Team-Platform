## Общая композиция страницы

Одна страница `/calendar` внутри `AppShell` (сайдбар слева, контент справа). Создание, просмотр и редактирование — **модальные окна** поверх текущего view (паттерн как у задач). Отдельных маршрутов `/calendar/new` нет.

```
┌──────────────┬──────────────────────────────────────────────────────────────┐
│  AppShell    │  CalendarView (client container)                             │
│  sidebar     │  ┌────────────────────────────────────────────────────────┐  │
│              │  │ CalendarToolbar — навигация, view switch, CTA          │  │
│  …           │  ├────────────────────────────────────────────────────────┤  │
│  Задачи      │  │ CalendarLayerFilters + CalendarLegend                  │  │
│ ▶ Календарь  │  ├────────────────────────────────────────────────────────┤  │
│  Командный   │  │ Active view: MonthGrid | WeekGrid | DayAgenda            │  │
│  чат         │  │ (или CalendarEmptyState при events.length === 0)         │  │
│  …           │  └────────────────────────────────────────────────────────┘  │
│              │  [ CalendarEventModal + CalendarEventForm — overlay ]        │
└──────────────┴──────────────────────────────────────────────────────────────┘
```

**URL state (deep link):** `?view=month|week|day&date=YYYY-MM-DD`  
**Часовой пояс отображения:** `Europe/Zagreb` (константа платформы)

## Глобальная карта: переключение view и фильтры

### Где переключение День / Неделя / Месяц

Расположение: **CalendarToolbar**, правая часть строки навигации, между кнопкой «Сегодня» и «+ Создать событие».

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ Календарь                                                                    │
│                                                                              │
│  [◀]  Июнь 2026  [▶]  [Сегодня]     ┌──────┬────────┬────────┐  [+ Создать] │
│                                     │ День │ Неделя │ Месяц  │               │
│                                     └──────┴────────┴────────┘               │
│                                     ▲ active: filled / underline             │
└──────────────────────────────────────────────────────────────────────────────┘
```

| Элемент | Поведение |
|---------|-----------|
| Segmented control | Три кнопки: **День**, **Неделя**, **Месяц** |
| Default при первом входе | **Месяц** (`view=month`) |
| При смене view | Обновить `view` в URL; пересчитать `from`/`to`; refetch `GET /api/calendar/events` |
| ◀ / ▶ | Шаг зависит от view: день → ±1 день; неделя → ±7 дней; месяц → ±1 месяц |
| «Сегодня» | `anchorDate` = сегодня в TZ Zagreb |

**PR-маппинг:** shell + переключатель в PR #4; day PR #5; month PR #6; week PR #7.

---

### Где фильтры: Мои события / События компании

Расположение: **вторая строка под toolbar** — компонент `CalendarLayerFilters`, слева; справа — `CalendarLegend` (легенда цветов).

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  … toolbar (см. выше) …                                                      │
├──────────────────────────────────────────────────────────────────────────────┤
│  ☑ Мои события          ☑ События компании          ● Личное   ● Компания  │
│     (personal)              (company)                 синий       зелёный    │
└──────────────────────────────────────────────────────────────────────────────┘
```

| Фильтр | `scopes` param | Default |
|--------|----------------|---------|
| ☑ Мои события | `personal` | включён |
| ☑ События компании | `company` | включён |

**Поведение:**
- Оба включены → запрос без `scopes` (или `scopes=personal,company`)
- Только «Мои» → `scopes=personal`
- Только «Компания» → `scopes=company`
- Оба сняты → показать предупреждение «Выберите хотя бы один слой»; не скрывать toolbar
- Состояние сохранять в `localStorage` key `calendar:layers`

**PR-маппинг:** UI фильтров в PR #9; в PR #4–#8 можно показывать оба слоя без UI-фильтра (всегда оба).

### Как визуально различать personal и company

| `scope` | UI-метка | Цвет | CSS token | Где применяется |
|---------|----------|------|-----------|-----------------|
| `personal` | «Личное событие» | Синий `#3B82F6` | `--calendar-personal` | Чип, блок в week, полоска в day, badge в модалке |
| `company` | «Событие компании» | Зелёный `#22C55E` | `--calendar-company` | То же |

**Правила отображения:**

```
Personal chip:  ███ Консультация          (синий фон, белый текст, левая полоска 3px)
Company chip:   ███ Общее собрание        (зелёный фон, белый текст, левая полоска 3px)
```

| Контекст | Personal | Company |
|----------|----------|---------|
| Month cell chip | Синий, max 3 + «+N ещё» | Зелёный |
| Week time block | Синий блок в колонке дня | Зелёный блок |
| Day agenda row | Синяя метка времени + заголовок | Зелёная метка |
| Modal badge | `Личное событие` (синий pill) | `Событие компании` (зелёный pill) |
| All-day | Серая полоска «Весь день» + цвет scope | То же |

**Дополнительный текст (не цветом):** в модалке всегда показывать тип события словами — для доступности и печати.

## Future CRM Linkage

**Статус:** Phase 2+ — не реализуется в MVP PR #4–#9. Зарезервировано в UX и модели данных.

В будущем событие календаря может ссылаться на клиента CRM. Поле `client_id` (nullable) и расширенный `event_type` появятся в схеме позже; в MVP `event_type` всегда `general`, `client_id` отсутствует.

### Зарезервированные поля (модель данных, Phase 2)

| Поле | Тип | MVP | Будущее |
|------|-----|-----|---------|
| `client_id` | `text` nullable | — | ID клиента из `/clients` |
| `event_type` | `text` | `general` | `consultation`, `document_submission`, `client_deadline`, … |
| `source_ref` | `jsonb` | — | Идемпотентность automation / promotion из CRM |

### Примеры связанных событий

#### 1. Консультация клиента

```
┌─ Консультация: Иванов Иван ───────────────────────────── [×] ─┐
│  ┌─────────────┐  ┌────────────────────────────────────────┐   │
│  │ Личное      │  │ 🔗 Клиент: Иванов Иван  → /clients/…  │   │
│  └─────────────┘  └────────────────────────────────────────┘   │
│  📅 21 июня 2026, 10:00 – 11:00                                │
│  Тип: Консультация (consultation)                                │
│  …                                                               │
└──────────────────────────────────────────────────────────────────┘
```

| Аспект | Значение |
|--------|----------|
| `scope` | `personal` (у менеджера-владельца) |
| `event_type` | `consultation` |
| `client_id` | CRM client id |
| Создание | Из карточки клиента или из календаря с выбором клиента |
| Видимость | Только owner менеджера; в карточке клиента — read-only для команды |

#### 2. Подача документов клиента

```
┌─ Подача документов: Петрова ──────────────────────────── [×] ─┐
│  ┌──────────────────┐  ┌───────────────────────────────────┐  │
│  │ Событие компании │  │ 🔗 Клиент: Петрова  → /clients/…  │  │
│  └──────────────────┘  └───────────────────────────────────┘  │
│  📅 25 июня 2026, 14:00 – 15:00                               │
│  Тип: Подача документов (document_submission)                 │
│  …                                                              │
└─────────────────────────────────────────────────────────────────┘
```

| Аспект | Значение |
|--------|----------|
| `scope` | `company` (видно всей команде) |
| `event_type` | `document_submission` |
| `client_id` | CRM client id |
| Создание | Automation из CRM-статуса или вручную с привязкой клиента |

#### 3. Дедлайн клиента

```
┌─ Дедлайн: подача визы — Сидоров ───────────────────────── [×] ─┐
│  ┌─────────────┐  ┌────────────────────────────────────────┐    │
│  │ Дедлайн     │  │ 🔗 Клиент: Сидоров  → /clients/…       │    │
│  └─────────────┘  └────────────────────────────────────────┘    │
│  📅 30 июня 2026  ·  Весь день                                  │
│  Тип: Дедлайн клиента (client_deadline)                          │
│  Источник: CRM поле «дата подачи» (virtual → persisted)         │
│  …                                                               │
└──────────────────────────────────────────────────────────────────┘
```

| Аспект | Значение |
|--------|----------|
| `scope` | `personal` или overlay-слой (Phase 2) |
| `event_type` | `client_deadline` |
| `client_id` | CRM client id |
| Источник | Виртуальное событие из CRM-дат; promotion в persisted по действию пользователя |

### Где зарезервировано в UX (MVP shell)

| Место | MVP (PR #4+) | Phase 2 |
|-------|--------------|---------|
| Форма создания | Поле «Клиент» **скрыто** | Searchable select клиента |

| Фильтры | Мои / Компания | + «С привязкой к клиенту» (опционально) |
